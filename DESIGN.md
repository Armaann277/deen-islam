# Design System: Subhana ♡

## 1. Visual Theme & Atmosphere

A deeply intimate, peaceful, and premium iPhone-first personal app. The atmosphere is dreamy, botanical, serene, and faith-centered — like a quiet digital sanctuary made for one person.

- Density: Art Gallery Airy (2)
- Variance: Offset Asymmetric (6)
- Motion: Fluid CSS (5)

## 2. Color Palette & Roles

### Foundation / Primary UI
- Amaranth (#933B5B) — Primary accent, active states, CTAs
- Thulian Pink (#B5728A) — Secondary text, subtle accents
- Brook Green (#AABAAE) — Muted botanical elements
- Chalk (#E3D6BF) — Primary background canvas
- Pomelo Olive (#9F9679) — Muted labels, metadata

### Soft / Interactive Accents
- Veranda Blue (#6BB1AD) — Interactive cards, Quran/Salah accents
- Sky Cloud (#A7BCBD) — Secondary calm surfaces
- Lychee (#EDECDB) — Card fills, surface containers
- Melon (#E5A9A9) — Soft highlights
- Cupid Pink (#E6748E) — Secondary accent

### Deep / Emotional / Night
- Warm Peach (#FCC59E) — Night mode warm highlights
- Coral (#FF9F9A) — Birthday reveal accents
- Rose (#E66277) — Birthday accent
- Deep Rose (#AD4161) — Night mode secondary surfaces
- Wine Rose (#8F3858) — Night mode primary surfaces
- Deep Plum (#562747) — Deepest visual anchor

## 3. Typography Rules

- Display: Georgia, serif (temporary placeholder)
- Body: system-ui, sans-serif
- Mono: monospace (prayer times, timers)

Typography is NOT finalized per the brief.

## 4. Component Stylings

- Cards: Rounded (12-16px), soft shadows, Lychee fills
- Buttons: Flat, tactile active state, Amaranth primary
- Navigation: Fixed bottom, 4 tabs, simple icons

## 5. Layout Principles

- Mobile-first iPhone portrait design
- Generous whitespace, calm hierarchy
- No website layouts, native app feel
- Rounded refined surfaces

## 6. Motion & Interaction

- Spring physics for interactions
- Subtle transitions (0.3s ease)
- Purposeful animation only
- Reduced motion support

## 7. Anti-Patterns (Banned)

- No loud birthday-party aesthetics
- No excessive saturated pink
- No generic SaaS dashboards
- No excessive gradients
- No heavy glassmorphism
- No neon colors
- No visual clutter
- No generic website layouts
